## Marquee 0.1.0

**The first release of Marquee.** One app for movies, TV and requests, with downloads through Lantern.

### What's in it
- **Movies and TV**: search TMDB, add titles, and see posters, seasons and episodes. Marquee answers the Radarr
  and Sonarr APIs at `/radarr` and `/sonarr`, so Prowlarr, Homepage, nzb360 and LunaSea work with it as they are.
- **Downloads through Lantern**: Marquee searches Lantern, picks the best release for the quality profile and
  size (each release it turns down says why), grabs it and shows it in Activity. Finished files are hardlinked
  into the library with Radarr's and Sonarr's names. Missing titles are searched every 6 hours.
- **TRaSH Guides by default**: quality profiles, custom formats and scores, sizes and naming for movies, TV and
  anime. A short wizard on the Quality page picks the resolution and source. Updates from TRaSH are checked
  daily, and anything you changed is asked about first.
- **Requests**: Discover and Requests pages, approvals, limits per account, Discord and ntfy news, and the Seerr
  API at `/api/v1` for apps that talk to Seerr.
- **Anime, first part**: a dub, dual-audio or subbed choice per account, the anime-lists id mapping, AniList
  seasons on request pages, and a check of a file's real audio and subtitle tracks with a Review queue.
- **From the kit**: What's new, copyable errors, bug reports, diagnostics and a web app that updates itself.

### Before you start
Set the Lantern address and API key under Settings, and a TMDB key. See README.md for the settings.
